# Alinhamento Brakmariano

Diário das 100 missões de alinhamento de Brâkmar (Dofus): check por missão, links para o guia
[Dofus pour les Noobs](https://www.dofuspourlesnoobs.com/alignement-bracirckmarien.html) (FR) e a
[Dofus Wiki](https://dofus.fandom.com/pt-br/wiki/Alinhamento) (PT-BR), e um cronograma ajustável
(padrão: 2 missões a cada 2 dias).

- `src/diario.html` — fonte da página (também publicada como artifact no claude.ai, onde o progresso é compartilhado).
- `index.html` — versão standalone gerada com `node build.mjs`. Nela o progresso fica salvo no navegador (localStorage).
